# solidworks-api project memory

Long-term, curated memory for the solidworks-api project: decisions, context, and progress that must survive across sessions. Keep it tight — it's read every session. Append entries to the Log; update in place when something changes. Per-session reflections live in `Sessions/`, not here. The universal cross-project log lives in the global `AgentDocumentationGlobal/Memory.md`.

## Format

```
### YYYY-MM-DD: Short title

Category: Decision | Context | System change

[1 to 3 sentences.]
```
